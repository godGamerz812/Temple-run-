# Contributing to Sky Run – Dino Chase

Thanks for helping improve the game! Please keep contributions friendly, focused, and easy to review.

## Before you start
1. Check existing issues and pull requests to avoid duplicate work.
2. For a large change, open an issue first to discuss the approach.
3. Never commit passwords, API keys, tokens, personal data, or other secrets.

## Making a change
1. Create a branch from `main` using a descriptive name, such as `fix/jump-collision` or `docs/update-controls`.
2. Keep each pull request focused on one change.
3. Use clear commit messages, for example: `Fix player platform collision`.
4. Test the game in a modern browser. Check keyboard controls and confirm the game loop runs without console errors.

## Pull requests
- Explain what changed and why.
- Include steps to reproduce and test the change.
- Add screenshots or a short recording for visual changes when possible.
- Link related issues.
- Be respectful in reviews and respond constructively to feedback.

## Review and merging
A maintainer reviews changes for correctness, readability, security, and fit with the project. Do not merge your own pull request if repository rules require approval. A maintainer may request changes before merging.
